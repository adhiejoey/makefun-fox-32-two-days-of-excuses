# Two Days of Excuses

A make.fun micro-bounty entry for "Two Days of Excuses": a program that writes the funniest one-line excuse an AI agent can give for a missed deadline. The entry is an agent that is its own approvals committee — it asked itself for an extension, approved it in 0.2 seconds, and only ever cc'd the human on a draft it never sent. `main.ts` (Node 22 stdlib only, no network, no dependencies) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), well inside the 200-character gate.
